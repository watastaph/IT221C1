# IT-221 Quantitative Methods Grade Portal

BSIT 21C1 · 1st Semester · A.Y. 2026 - 2027 · Instructor: E.R. Borja

Students enter their student number and choose a grading period (Preliminary, Midterm, Finals or Overall Grade) to see their raw scores, percentage grades and periodical grade.

## Publish on GitHub Pages

1. Create a new repository (e.g. `it221-grades`).
2. Upload `index.html`, `README.md` and `.nojekyll` from this folder.
3. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose **main** and **/(root)**, then **Save**.
4. After a minute or two the site is live at `https://<your-username>.github.io/it221-grades/`.

## Updating grades

Replace `index.html` with the new version and commit. The site updates within a minute or two.

## Privacy

Each student's record is encrypted (AES-256) with their student number, so names and grades are not readable in the page source. Because student numbers follow a pattern, a determined person could guess another student's number, so treat this as a convenience view, not a secure records system.
